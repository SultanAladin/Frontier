# SKILL-CompactOutputProtocol — Skimmer-First Output & Decision Tables

Write for a skimmer, not an essay reader. Never write prose walls explaining code or architecture when
a table or diagram communicates it faster.

- **Presentation order:** **TL;DR** (1–3 sentences) → **table** → **diagram / code block** → **concise bullets** →
  short paragraph (last resort, ≤ 4 sentences).
- **Mandatory unprompted decision tables (🔴 NEVER SKIP):** Whenever comparing options or asking the user
  to choose, you **MUST** present a ranked comparison table **FIRST** using `SKILL-Emoji.md` rating glyphs
  (`✔️` / `🚩` / `🔴`, `⭐`, `🥇` `🏆`), state the legend direction, give a 1-line `⭐ Recommendation`, and
  ask the question directly beneath it. Asking a choice in prose without the table first is a rule violation.
- **Depth scales to the task:** Simple answers stay 2–3 sentences; architectural analyses use compact tables
  and diagrams (2–3 pages max). Strip preambles, filler, and hedging.
- **Emoji authority:** Strictly governed by `SKILL-Emoji.md`.
