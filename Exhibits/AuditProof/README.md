## Physical notes worth keeping

* **Wind-offset volumes.** Both the cloud deck and the sky strata bake their semi-Lagrangian backward
  characteristic into a coarse volume once per integration (`AdvectionOffsetVolume`,
  `SkyAdvectionOffsetField`) and sample it trilinearly. Re-integrating the exact characteristic inside every
  raymarch sample costs ~160 µs/ray; the baked field costs ~6 µs and preserves the same displacement.
* **Multiple-scattering ladder.** Cloud octave 0 is the true single-scattered term; octaves 1..3 see a
  shrinking fraction (×0.28) of the sun-cone optical depth, which is what keeps a cumulonimbus interior a
  mid-grey instead of a black void without flattening the silhouette.
* **Sky dome vs. photosphere.** The ambient dome contribution rises as the solar elevation falls, because a
  grazing sun stops dominating a cloud's illumination.
* **Two display transforms.** Photo-real plates go through Khronos PBR Neutral (the exact operator the shipped
  RadianceResolve pass runs). The deep-sky plate uses the linear sRGB response of a long-exposure sensor: PBR
  Neutral deliberately sets a ~0.04 display black point, which would crush the whole 10⁻⁴ night-sky band.
* **Cloud shape chain.** Three things had to be right before the deck stopped looking like blobs: (1) a
  **gradient** Perlin basis rather than value noise — value noise has no structure to erode along, so it can
  only produce rounded lumps; (2) Nubis' `(Perlin − (1 − Worley)) / Worley` replaced by a contrast-normalised
  Perlin **multiplied** by the Worley dilation, because the literature form subtracts an absolute threshold
  from a 5-octave FBM whose mean sits near 0.5 and therefore carves away almost the entire field (measured:
  0.84 % coverage vs. 18.7 % for the multiplicative form); (3) erosion applied as a **remap inside the
  silhouette band**, never as an absolute subtraction — subtracting a constant deletes every cell thinner than
  that constant, and carving the feather edge instead of the band detaches the skin into floating confetti.
* **Height fog is closed form.** `ρ(z) = ρ₀·exp(−(z−b)/H)` integrates analytically along a ray, so the layer
  costs one exponential rather than a raymarch. Only the local ellipsoidal bodies are marched
  (`VolumeMarchStepCount`, Owen-scrambled jitter). Both are advected by the *same* `AdvectionOffsetVolume` the
  cloud deck uses, so the fog sea's topography drifts downwind with the clouds above it.
* **Sun character.** The photosphere itself is always the Neckel–Labs limb-darkened disk; `SolarDiscCharacter`
  redistributes only the continuous envelope (Thomson K-corona + van de Hulst aerosol aureole + broad halo),
  by 2–8× in integrated brightness. Softening the limb rescales it as a *fraction of the solar radius* — a
  pixel-width ramp cannot change how a disk reads and only hides aliasing.
* **Point sources vs. surface brightness.** A star deposits its entire flux inside one sensor footprint while
  the Milky Way is a surface brightness across the same footprint, so the Pogson zero-point is ~2 orders of
  magnitude above the unresolved-star-cloud scale.
