# Environment inspector evidence

Status: experimental work in progress; comparisons do not establish pixel parity or production
renderer integration.

## Reference

Source: `Experimental/VehicleHmiPrototype` at upstream commit
`6afb6f00b5f25c45f7cda92c7da65b64845768f3` (`arena/e9bd7db5-frontier`). Native base:
`4bde2fe993e9bc6ab07abcddaca836fcab0b28d1` plus current uncommitted changes. Extract both
`Experimental/VehicleHmiPrototype` and `ReferenceApps` from that tree to run it; start
`python3 Tools/Serve.py` in the demo directory. Reference source includes
`SunInspectorDashboard.js`, `CelestialSolver.js`, `CloudInspectorDashboard.js`,
`CloudSettings.js`, `CloudField.js`, `AtmosphereInspectorDashboard.js`,
`AtmosphereIntegrator.js`, `NativeFlarePanel.js`, and `NativeLensFlareKernel.js`.

`Images/sun-*.png` and `Images/reference-{clouds,atmosphere,flare}-*.png` are **browser**
reference captures, not native C++. They were captured on Debian 12 with Chromium
153.0.8010.0, Playwright Core 1.64.1 and SwiftShader at 1440 × 900. Software WebGPU was
frozen after the first frame, with low quality, quarter scene scale and no stress pool.
The pixelated scene and incomplete asynchronous GPU previews reflect capture constraints.
`Images/ScrollReference/` additionally contains the 379 × 838 inspector viewport at the top,
end and, for long tabs, intermediate scroll positions; filenames encode panel, tab and scroll offset. With the reference server running,
install `playwright-core` and `@sparticuz/chromium` separately, set `NODE_PATH` to that
installation, and run:

```sh
node Exhibits/SunInspector/CaptureReference.cjs
node Exhibits/SunInspector/CaptureEnvironmentReference.cjs
node Exhibits/SunInspector/CaptureScrollReference.cjs
```

`GenerateSolarRaster.cjs` reproduces the transparent PNG from the upstream SVG now under
`Experimental/EnvironmentInspectors/Icons/`. The SVG matched the upstream source byte for
byte; the PNG was regenerated byte for byte in the capture environment.

## Native capture and verification

`Images/native-{sun,cloud,atmosphere,flare}-*.png` show experimental C++ ImGui draw commands
rasterized by `NativeValidation.cpp`, not browser mockups. `Images/comparison-*.png` place
an unscaled 380 × 839 reference crop on the **left** and the corresponding C++ crop on the
**right**. The reference metric may show GPU timing; native shows a dash unless the host
provides one. Image dimensions, font handling, GPU availability, anti-aliasing, preview
resolution and the requested Material Workspace slider style differ. These images expose
remaining differences rather than prove 1:1. `native-scroll-*-end.png` captures the actual
ImGui window at the end of each scrollable tab using pristine defaults. `comparison-scroll-*.png`
puts the browser's end viewport on the left and the bottom 838 pixels of the 900-pixel native
host on the right. Differences in scroll height and the browser footer remain visible. Regenerate
the native and comparison files after running the validation target with:

```sh
Exhibits/SunInspector/GenerateComparisons.sh <build>/experimental-environment-evidence
```

The comparison script requires ImageMagick `convert`.

Images prefixed `historical-production-` show the prior Sun overview increment accepted by the
user as good enough; its production hook was removed to keep the prototype in `Experimental/`.

With pinned dependencies and fonts prepared, reproduce on Linux with CMake 3.31 and GCC 12.2
(or use the project's usual native build setup):

```sh
cmake -S . -B <build> -DFRONTIER_HOST_VERIFICATION=ON \
  -DFRONTIER_EXPERIMENTAL_ENVIRONMENT=ON -DGLFW_BUILD_X11=OFF \
  -DGLFW_BUILD_WAYLAND=OFF -DCMAKE_BUILD_TYPE=Debug
cmake --build <build> --target ExperimentalEnvironmentValidation EverestInterfaceValidation \
  EverestShippingValidation InterfaceValidation IconDomainValidation
ctest --test-dir <build> --output-on-failure \
  -R '^(ExperimentalEnvironmentValidation|EverestInterfaceValidation|EverestShippingValidation|InterfaceValidation|IconDomainValidation)$'
```

On this host, **5/5 selected checks passed**. The focused test injects actual ImGui pointer
input for Sun vector, toggles, reset, tabs, daylight graph and flare navigation; cloud mix,
slider, wind/lightning actions; atmosphere probe, bake toggle and callbacks; and flare source,
tabs and HDR export callback. It verifies the Sun solver, seeded cloud density/atlas, RGB
atmospheric transmission and flare radiance against upstream output; tests PFM row order and
byte encoding; and generates the native tab and scrolled captures. Keyboard event injection
checks the Sun vector/day graph, cloud mix/slider/layer-stack, atmospheric column/height
comparator and flare source/ghost/halo (including Home and Shift-arrow behavior), plus the
flare source's minimum and maximum bounds. These checks require ImGui keyboard navigation to
be enabled by the host; they do not establish full keyboard/accessibility parity. GPU preview callback dispatch is
checked without substituting fake images in retained captures. General workspace/shipping/UI/icon
checks verify existing production code. Full suite, Windows/MSVC, display-server, Vulkan,
persistence and actual renderer behavior were not tested. The [prototype README](../../Experimental/EnvironmentInspectors/README.md)
describes the host contract and unfinished work.
