1 Two-Tier Hybrid Container (DocumentContainer)

TOML Manifest + SFNT/TTF Binary Directory
Core Mechanism: Every Frontier document on disk is a single self-contained file. The top of the file is human-readable UTF-8 PascalCase TOML (inspectable in any text editor or Git diff); after an explicit delimiter padded to 64 bytes, packed binary sections sit back-to-back like OpenType/TTF sfnt tables for zero-parse $O(1)$ slice access and FNV-1a 64-bit integrity verification.

3 Parametric Document Revision & Memory Ceilings

215 MiB Per-Document · 750 MiB Global Application Cap
Why Parametric Operations Fit Easily in 215 MiB:
Instead of saving full rasterized 4K snapshots per undo step (~64 MiB each = 3 undos!), WorkspaceDocument records compact OperationRecordEntry structs (48 B – 2 KiB: spline control points + brush seed, exposure delta, layer blend change, or feature parameter). 215 MiB holds 100,000+ to 1,000,000+ operations and reconstructs the document at any resolution.
Two-Tier Memory Ceiling Enforcement:
① Document Ceiling (215 MiB default): Enforced inside each WorkspaceDocument.
② Global Ceiling (750 MiB default): Enforced by RevisionExtension across all open documents in WorkspaceLifecycle (e.g. 4 heavy documents open simultaneously). 
struct alignas(16) OperationRecordEntryHeader   // 32 Bytes fixed header + trailing parametric payload bytes
{
    uint64_t GlobalSequenceStamp = 0u;          // [id]    - Monotonic cross-document stamp for Global Undo / Redo
    uint32_t LocalRevisionIndex  = 0u;          // [idx]   - 1-based ordinal inside owning WorkspaceDocument
    uint32_t OperationCategory   = 0u;          // [id]    - Domain operation tag (e.g. StrokeAppend, ExposureAdjust)
    uint32_t PayloadByteLength   = 0u;          // [bytes] - Exact byte length of parametric forward/inverse payload
    uint32_t ChecksumFnv32       = 0u;          // [hash]  - Payload integrity hash
    double   RecordedTimestamp   = 0.0;         // [s]     - Session elapsed timestamp for timeline coalescing
};
static_assert(sizeof(OperationRecordEntryHeader) == 32u);
