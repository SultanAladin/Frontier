Importing into Blender (Recommended: .GLB)

1. Open Blender → File → Import → glTF 2.0 (.glb/.gltf).
2. Select any .glb file — hierarchy groups (Body, Wheels, HoodTwinTurbo, etc.) and PBR materials import automatically at exact 1:1 metre scale.
3. To edit individual parts, expand the hierarchy in the Outliner and select any mesh (e.g., Cuda_TrapezoidHood, RearSpoiler_MainWing, Turbo_Impeller_R).
