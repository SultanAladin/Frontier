Known gaps found while reading (no edits made)

  • Lost branch. arena/73e163a3-frontier carried Experimental/TextureStudio/ — 1 519 files / 428 836 lines, the React+Vite "Alloy" studio (Material · Pattern · Texture · Stamp · Baking) plus Exhibits/Renderer/ with the real Vulkan readback evidence. None of that exists on this branch. That is the material workspace work that went missing.
  • Vulkan proof renderer is absent here. Exhibits/ currently holds only Diagnostics/. There is no Exhibits/Renderer/index.html, no Images/, no Results/ JSON on this branch.
  • Workspace.html dock is dead. Its iframe src="AssetBrowser.html" resolves to a file that is not in Documentation/Prototypes/ — it 404s in the browser.
  • Offline runtime imports. Workspace.html pulls unpkg.com/lucide@latest and api.fontshare.com; icons and the chosen font will not appear in this sandbox.
  • WebGPU in this browser. MaterialShelfDrawer.html hard-requires navigator.gpu and shows a fatal panel when it is absent. If the panel reports "WebGPU unavailable", that is the renderer, not the prototype's fault.
