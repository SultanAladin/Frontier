# Experimental

Requested prototypes, experimental HTML, scripts, styles, assets, and launchers belong together here.
Do not place reusable production code or permanent validation reports here.
The approved C++ editor comparison mirror belongs in `Exhibits/EditorMirror/`.
Existing prototypes have not yet been moved out of `Documentation/Prototypes/`.
Review launcher and asset references before migration.

## Illumination prototype

`IlluminationPrototype/` contains the consolidated WebGPU/WGSL vehicle/GI app, local assets, locked dependency
setup and Windows source launcher. See its README for controls, genuine LM-63 support, reduced-order XPBD scope
and timing toggles. Retained outputs are under `Exhibits/IlluminationConsolidation/`.
